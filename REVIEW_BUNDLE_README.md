# CitePrism review bundle

This archive is for architecture, code-quality, security, data-contract,
evaluation, reproducibility, and UX review. It contains the current source
working tree plus review metadata. It deliberately omits credentials, virtual
environments, research-data contents, PDFs, database rows, caches, logs, model
files, archives, and build artifacts.

The `_review_info` folder explains what was included and excluded. Database
schema is provided without records. If later review requires representative
input/output, provide only an explicitly approved, de-identified sample with
known usage rights.
